# 因子挖掘中的过拟合与防治

来源：[[wiki/code/alpha-mining-demo-notes]] 过拟合核查节的延伸分析。

## 核心教训（demo 实证）

alpha_mining_demo 的实测给出了一个教科书式案例：**样本内最漂亮的因子，样本外不如最简因子**。

- VP_COMBO（三项加权）valid RankIR 0.51 → test 跌回 0.28，被单一因子 VP_ANTI_RES5（valid 0.40 → test 0.28，test 多空 Sharpe 1.81 vs 1.42）全面追平甚至超越。
- 三成分近正交（截面 Spearman 0.23/0.07/0.03），说明过拟合向量**不是因子项数，而是参数**——权重 0.5/0.7、窗口 5/12/3/10 由 134 个候选在 7 轮迭代中于同一段仅 488 天的 valid 上选出，是典型的**选择偏差（selection bias / multiple testing）**。

数学直觉：若在同一段 valid 上尝试 N 个候选，即使所有候选都是噪声，最优者的样本内指标期望也随 N 增大而系统性偏高。valid 段越短、候选越多、迭代轮次越多，"valid 优势"中属于运气的比例越大。

## 放大器与量化锚点（2026-09-16 二次 query 补充）

选择偏差的实际烈度取决于四个常被低估的放大器；前两个还提供了判别真伪的量化锚点。

**锚点：噪声最优值 ≈ √(2·ln N)**。若 940 次尝试全是噪声，最优 |t| 的期望约 √(2·ln 940) ≈ 3.7——"孤立地看很显著"（t≈3~4）恰恰是多次尝试下噪声的典型产出。对照 demo：主推单因子 valid RankIR 0.40，naive t = 0.40×√488 ≈ 8.8，按重叠 label 折半有效样本后仍 ≈6，**远高于噪声上限 3.7**，与其 test 段存活、且 2021–2023 累积 RankIC 斜率不衰吻合；而 combo 相对单因子的 valid 增量 0.11（naive t≈1.7）**完全落在选择噪声射程内**，与其 test 段归零吻合。判别式：区分**绝对优势**与**增量优势**——只有前者可能穿过多重检验存活。

1. **重叠 label 压缩有效样本**：label 是 T+1→T+3 的 2 日收益，逐日重叠 → IC 序列呈 MA 型自相关，Hansen–Hodrick 修正下有效样本 ≈ 488/2 ≈ 244；5 日窗口因子自身的平滑会进一步压低。"488 天"是日历口径，候选预算与显著性门槛应按**有效样本**设定，t 值用 Newey–West / block bootstrap（lag ≥ label 视界）。
2. **LLM 迭代 = 自适应搜索，试验不独立**：第 t 轮候选以第 t−1 轮 valid 指标为条件生成，7 轮 × 134 是一族**相依试验**，Bonferroni 式按 N 折减会低估问题；早停规则本身也是数据依赖的选择机制。适配工具是 White's Reality Check / Romano–Wolf step-down。工程对策：预算与停机规则在第 1 轮前写死（预注册思想），每条尝试含失败进 trace——`runs/round_*/notes.md` 已是雏形。
3. **valid 是消耗品**：2015–2016 已被本项目 ~940 次尝试"用过"，同一仓库后续任何挖掘 run 复用这段 valid 都继承累积选择偏差——过拟合不只发生在单次 run 内，也发生在**项目的试验史**里。对策：按时间段维护试验台账（ledger），定期换新段，最终裁决只用从未参与任何 run 的样本。
4. **数据侧的隐性抬升**：成分池若非 point-in-time（幸存者偏差）、未剔除停牌/涨跌停（反转类因子恰恰想买昨日跌停卖不出的票），样本内指标被系统性抬高，方向与过拟合一致。解药是多宇宙检验 + 可交易性校验（report.md 局限性已自承）。

## 防治手段（按管线阶段）

### 1. 搜索阶段：限制搜索自由度

- **候选预算约束**：预先固定总候选数上限并记录（demo 实际 7×134≈940 次有效尝试，事后才统计，应事前声明）。候选数应与 valid 长度挂钩，而非与 LLM 耐心挂钩。
- **参数网格取平台而非峰值**：对窗口/权重做邻域敏感性分析，只有"参数平台"（邻域内指标都稳健）才可信，尖峰最优点大概率是噪声。可输出 RankIR 对参数的二维热力图。
- **复杂度惩罚**：候选公式越复杂（项数、嵌套、窗口数）门槛越高，类似 BIC 的思想。

### 2. 验证阶段：让选择偏差无处遁形

- **嵌套验证（nested CV）**：外层留出最终检验段，内层做所有调参/选因子决策——demo 中 test 只用于终局确认已是此思想的弱形式，但参数是在 valid 上选的，valid 已被"污染"，不再是干净的样本外。
- **滚动/走查验证（walk-forward）**：把 2008–2020 切成多个滚动 train/valid 窗口，看因子是否在**每个**窗口都稳定，而非只在一段.valid 上好。
- **Deflated Sharpe / 多重检验校正**：对"940 次尝试后的最优"按尝试次数折减显著性（Bailey & López de Prado 的 Deflated Sharpe Ratio 思想）。
- **多宇宙检验**：换股票池（中证500/全市场）或换市场重算，真信号通常跨池存活。

### 3. 组合阶段：减少可调参数

- demo 的直接教训：**正交成分等权组合**就足够，不要再调权重——VP_COMBO 与 CONSERVATIVE（权重收缩版）test 表现几乎相同（1.42 vs 1.44），说明在 valid 上精调权重没有带来任何样本外增益，纯粹增加了过拟合面。
- 优先保留有经济逻辑（A股短线量价同动 = 情绪过热反向信号）且形式最简的因子。

### 4. 评估口径：别让指标本身骗人

- 换手×成本后指标（demo 已有一行估算，应升级为硬约束：高换手因子按扣费后排序）。
- IC 序列的时序稳定性（滚动窗口 RankIR 的分布/最差区间），而非全段均值。
- 分年度看，警惕依赖个别年份（如 2015 异常波动）的因子。

## 在本 demo 中落地的最小改动清单

1. 迭代前在 config.json 声明候选总数预算与早停规则（已有雏形）；
2. 留存因子时附带参数邻域敏感性表（±1 窗口、±0.1 权重）；
3. 把 valid 一分为二（2015 / 2016），前半选参数、后半选因子，恢复一层干净样本外；
4. combo 一律等权，不再暴露权重给搜索；
5. 报告固定给出"尝试总次数"字段，提醒读者对最优指标打折解读；
6. 试验台账：按时间段累计尝试次数（跨 run 持续追加），"尝试总次数"从台账读而非事后手数；
7. 显著性口径：IC 的 t 值用 Newey–West（lag ≥ label 视界 2），与 √(2·ln N) 噪声上限对照后再解读；
8. 留存决策三分之二多数：**绝对优势（超噪声上限）+ 经济机制 + 最简形式**三票至少两票才留存；相对已有因子的 valid 增量单独不构成留存理由。

## 样本消耗审计与剩余盲点（2026-09-18 三次 query）

前两轮 query 解决了"单次 run 内"的防治（预算/平台/锚点/台账，已在反转、动量两次实测落地）。第三次方向实测（动量/共振，6 轮 × 84 候选）完成后，用 `runs/final/` 实际产物回看，发现**选择偏差正向三个新出口转移**——纪律没有失效，而是被成功的流程推到了未被覆盖的地方。

### 盲点 1：test 段正被跨方向比较慢性消耗

"test 只用于终局确认"在单次 run 内成立，跨 run 累积后失效。审计证据：

1. 三个方向（VP/REV/MOM）各自做了一次 test 终局确认——同一段 2017–2020.08 已被观察三次；
2. 笔记与日志以 "PV_ANTI_TRIPLE test Sharpe 2.53 > REV_TRIPLE 1.57、2024 年 +0.103" 论证其"三方向主推中样本外最稳"——**跨方向排序已经在 test（及 2020.09–2024 分年数据）上做出了选择**，test 事实上已是第二个 valid；
3. 拟议的 REV_TRIPLE × PV_ANTI_TRIPLE 合并决策若再引用 test 段相关性/表现，消耗继续。

判别标准不是"看没看"，而是**结果是否反馈进决策**：确认之后不回头改选择，才算确认；看了 test 排序再定主推，就是选择。对策（lockbox 纪律）：

- 宣布 2017-01 起的全部数据对**一切选择**只读（跨方向排序、合并、因子去留均不得引用）；跨方向比较若必须做，只报告不排序，或按台账尝试总数折减后解读；
- lab 数据实际延伸到 2024（config 的 `end: 2023-12-31` 只约束 eval 分段，终局报告用全量数据），**2020.09–2024 是仅存的从未参与任何选择的样本**，应明示保留为项目级 lockbox；
- 下一个挖掘方向启用新 valid 段（或换股票池），不再复用 2015–2016。

### 盲点 2：无成本 IC 口径掩盖成本与可交易性

PV_ANTI_TRIPLE 多头组日均换手 54.8%，单边 0.1% 下年化拖累约 26.7%（多空年化 58.4% → 31.7%）。现有全套纪律——参数平台、噪声锚点、简形式——都建立在无成本 RankIR 上，即**门槛量与实盘可用性脱节**。两个落地缺口：

- 成本敏感性进留存门槛：单边 0.05/0.10/0.15% 三档下扣费后因子排序不变才留存（高换手因子对成本假设最敏感）；
- 可交易性与池子口径：反转/过热族想交易的票恰是涨跌停、停牌不可成交的票（至少剔除当日一字板再算 label 侧收益）；859 只池的 point-in-time 性未核查——若成分股按"今天的名单"回看历史，则叠加幸存者偏差，方向与过拟合一致（放大器 4 仍停留在纸面）。

### 盲点 3：因子衰减可见，而"样本外"是四年前的市场

PV_ANTI_TRIPLE 分年 RankIC：2015 年前 0.05–0.065 → 2021–2023 降至 0.02–0.04（2024 反弹 0.103）；REV 族更甚（2023–2024 ~0/−0.13）。train/valid/test 全部位于 2020.08 之前——**报告主表的"样本外"本身已是 4 年前的市场**，衰减意味着不能把历史样本外读作当前期望。另注意 "18/18 年 RankIC 为正" 含 8 个 train 年份，作样本外证据引用时应只数 2017 年起（8/8）。对策：留存门槛增加"最近三年 RankIC 不低于 train 水平的一半"类条款；报告显著标注样本外终点与衰减。

### 修订后的优先级（对下文 8 条清单的增量）

1. **lockbox 纪律**（盲点 1，新增且最紧迫——每次跨 run 比较都在消耗最后的干净样本）；
2. valid 一分为二 / 滚动验证（清单第 3 条，两次实测均未落地）；
3. 扣费后三档成本门槛（清单第 4 项评估口径的硬化）；
4. 池子 point-in-time + 涨跌停可交易性核查（放大器 4 的落地）；
5. Romano–Wolf / block bootstrap 相依多重检验（噪声锚点的独立性假设对 LLM 迭代偏乐观）。
